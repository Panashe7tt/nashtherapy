NASH THERAPY - UPDATED WEBSITE

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the nash-therapy-full folder in Visual Studio Code.
3. Use the Live Server extension and open index.html.
   (You can also open index.html directly in a browser.)

FEATURES ADDED
- Live therapist search, specialisation filter and gender filter.
- Three-question therapist matching quiz.
- Daily mood check-in with a seven-entry recent history.
- Booking cancellation and rescheduling from the student dashboard.
- A Need help now panel on every page with South African support numbers.
- Messages can be typed, displayed and retained for the current browser account.
- Larger text and high-contrast accessibility options, alongside the existing dark mode.

IMPORTANT PROTOTYPE LIMITATIONS
This project is a front-end demonstration. Accounts, bookings, mood history and messages use browser localStorage, separated by the locally signed-in email. They are not stored on a secure server, synchronised across devices, or sent to a real therapist. Do not enter real confidential or medical information. A production service needs a secure backend, authentication, database, encryption, privacy controls and verified clinician workflows. The help panel is signposting only and is not an emergency response service.
